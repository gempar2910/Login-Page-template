# Login & Sign Up Page Template 🚀

Project ini adalah template antarmuka (UI) untuk halaman Login dan Sign Up modern. Dibuat sebagai latihan implementasi **Semantic HTML**, **CSS Variables**, dan **CSS View Transitions API**.

## 🛠 Teknologi yang Digunakan
* **HTML5** - Struktur semantik.
* **CSS3** - Styling, Flexbox, dan Animasi.
* **Google Fonts** - Tipografi (Poppins).
* **Git** - Version Control System.

## ✨ Fitur Utama
1.  **Smooth Page Transition:** Efek animasi lingkaran yang berpindah halus antara halaman Login dan Sign Up.
2.  **Responsive Design:** Tampilan menyesuaikan layar HP dan Desktop.
3.  **Interactive UI:** Efek hover pada input dan tombol.
4.  **Clean Code:** Struktur folder CSS yang rapi dan terpisah.
